## TL;DR
Ben Thompson’s Mac Mini was recently hacked via a zero-day screen sharing vulnerability, leading him to rely on an AI agent (Claude) to root out the malware; this incident, combined with frustrating TCC permission prompts and Apple's tightening restrictions on full-disk access, has made him envision a future where he no longer purchases Apple products by default.

## Security Breach and AI Agent Recovery
* **The Vulnerability (CVE-2026-65400):**
  * Discovered at the Black Hat security conference and patched by Apple in macOS Tahoe, Sequoia, and Sonoma.
  * A 7.1/10 severity bug in macOS screen sharing allowed remote unauthenticated code execution when port 5900 was exposed to the internet.
  * Exploitation resulted in root access and the installation of a Monero crypto miner.
* **Agent-Driven Incident Response:**
  * Thompson's always-on Mac Mini ran Claude via a dedicated thread to log ideas and manage status boards.
  * Claude's monitoring tool triggered an urgent alert: *"The Mac Mini looks compromised. Someone with admin root access has planted a crypto miner on it."*
  * Claude unilaterally stopped executing commands, noted unauthorized admin privileges, and suggested remediation steps.
  * Thompson used Claude to isolate the 4-second breach window, create monitoring tools, and ultimately wipe the machine before discovering the NCSC advisory.

## Apple's Security Constraints vs. Headless Agent Hosts
* **Friction with TCC (Transparency, Consent, and Control):**
  * TCC governs permissions for cameras, downloads, network shares, and desktop access via GUI-only prompts invisible to software running in userland.
  * For headless servers running autonomous agents, TCC is a disaster because agents constantly write new programs that trigger invisible prompts, causing silent failures.
  * Thompson argues TCC operates at the wrong level of abstraction; he needed an agent-level permission layer rather than program-level blocks.
* **Update Confusion:**
  * Critical security patches typically arrive in point releases rather than background security updates, leaving users exposed despite believing their systems auto-update.
* **Full Disk Access Crackdown:**
  * Apple released a developer note warning that full disk access sidesteps controls and poses privacy risks as AI agents grow more autonomous, signaling upcoming restrictive changes.

## The Hacker's Future and AI-Driven Computing
* **The Evolution of the Hacker:**
  * Referencing Paul Graham's 2005 essay *Return of the Mac*, hackers originally adopted Macs because Mac OS X ran FreeBSD.
  * Today, AI and autonomous agents democratize hacking: anyone with volition and ideas can build custom software and decompile existing programs.
* **Shifting Away from Apple Defaultism:**
  * While not predicting Apple's downfall, Thompson notes that walled gardens feel increasingly like prisons in an agent-driven world.
  * Thompson purchased a new Linux server, vowing never to put a Mac in a rack again, and can envision a future where he stops buying Apple by default.
