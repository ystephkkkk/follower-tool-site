## The Shift to Agentic AI and DSX AI Factories
* **The Rise of Agentic AI:** AI has transitioned from static generative models to active agents that observe, reason, plan, use digital tools, and manage short-term and long-term memory.
    * **Developer Productivity:** Software developer output has nearly tripled as agents automate coding workflows. A $3 trillion global software salary base is now producing an estimated $9 trillion in productivity, driving companies to hire *more* developers rather than fewer.
    * **The "Tokens as Revenue" Economy:** Compute has transitioned into direct revenue and profit. Because every AI-generated token represents profitable revenue, compute demand is now the primary constraint for global enterprises.
* **NVIDIA DSX Infrastructure:** A full-stack reference design and operating system blueprint for constructing gigawatt-scale AI factories.
    * **DSX Sim:** Utilizing NVIDIA Omniverse, partners can build, simulate, and validate a digital twin of a Vera Rubin AI factory before physical construction begins.
    * **DSX MaxLPS:** Safely deploys more GPUs within the same power budget, eliminating the 40% power overprovisioning common in traditional data centers and unlocking billions in annual revenue.
    * **Resource Efficiency:** Features advanced 45°C liquid cooling to decrease water and energy use, alongside dynamic power allocation to steer power from rack to rack where active workloads are occurring.

## Vera Rubin and the Agent-Optimized Vera CPU
* **Vera Rubin Platform:** Built specifically for processing agentic AI loops, this multi-rack, pod-scale supercomputer is now in full production.
    * **Hardware Specifications:** Built on TSMC's 3nm process, utilizing CoWoS advanced packaging, and HBM4 memory from Micron, SK Hynix, and Samsung. The GPU features 6 trillion transistors and over 18,000 components on a single board.
    * **Assembly Simplification:** A new PCB midplane design completely eliminates external cables, hoses, and fans. Racks that previously took two hours to assemble can now be constructed in five minutes, drastically scaling production capacity.
    * **The Rubin Pod System:** Integrates Vera Rubin NVL72 (for thinking and reasoning), Vera CPU racks (256 liquid-cooled CPUs for orchestration), Foxconn/Quanta Vera LPX racks (256 Groq LPUs for ultra-low latency token generation), and Vera BlueField-4 STX (for accelerated storage and memory security).
* **The Vera CPU:** Designed from the ground up for agentic workflows rather than human-rented cloud cores.
    * **Olympus Core:** A custom data center core optimized for branch-heavy Python runtimes, tool calls, and sandboxed code execution.
    * **Performance Metrics:** Features the world's highest instructions per clock (IPC), fetching, decoding, and executing 10 instructions per clock. It delivers 1.8x the agentic sandbox performance of traditional x86 CPUs.
    * **Bandwidth and Coherency:** Utilizes LPDDR5X memory with 1.2 TB/s bandwidth (reducing peak memory latency by 40% compared to x86). It is unified by a monolithic coherence fabric delivering 3.6 TB/s of core-to-core communication.
    * **Workload Acceleration:** Accelerates SQL database processing by 3x and real-time stream processing (developed in partnership with the New York Stock Exchange) by 6x.

## Reinventing the Personal Computer: RTX Spark
* **RTX Spark Processor:** Fuses a Blackwell RTX GPU (featuring 6,144 Tensor Cores and 1 petaflop of AI performance) with a custom 20-core Grace CPU developed in partnership with MediaTek.
    * **System Architecture:** Manufactured on TSMC's 3nm process with 70 billion transistors and 128 GB of unified memory. 
    * **Software Ecosystem:** Built in deep collaboration with Microsoft to run 100% of classic Windows applications, alongside the entire CUDA-accelerated library suite natively on-device.
* **New Agentic PC Lineup:** NVIDIA is introducing three form factors designed to run local, meter-free AI agents 24/7:
    * **RTX Spark Laptops:** Run local, private AI agents that can orchestrate complex, multi-application workflows (such as CAD modeling in Rhino, rendering in Blender, and generating photorealistic images via Flux 2) entirely on-device.
    * **Desktop PCs:** Desktop systems (such as those from MSI) act as secure, continuous home servers connected to IoT devices, home security, and personal data.
    * **DGX Station:** A localized developer workstation featuring 768 GB of memory and 20 petaflops of compute, enabling developers to run and train trillion-parameter models directly at their desks.

## Physical AI, Autonomous Vehicles, and Humanoid Robotics
* **Cosmos 3 Physical AI:** An open frontier omni-model built on a Mixture of Transformers architecture. It functions as a Visual Language Model (VLM) to perceive physical environments and a world model to generate physics-accurate synthetic video for robot training.
* **Alpamayo 2 Super:** The world's first reasoning autonomous vehicle model. Running on the DRIVE Hyperion platform, the model continuously "thinks aloud," planning driving actions, predicting traffic patterns, and navigating complex urban environments.
* **Isaac GR00T Humanoid Platform:** An open, modular reference platform designed to accelerate humanoid robotics research.
    * **Sharpa Reference Robot:** A fully integrated 6-foot, 150-pound humanoid robot featuring 25 degrees of freedom on each hand and 31 degrees of freedom overall.
    * **Compute and Software:** Powered by Jetson Thor running Isaac Lab and Isaac ROS, allowing researchers to capture human teleoperation, scale data in simulation via Cosmos, and deploy physical policies in hours rather than months.
