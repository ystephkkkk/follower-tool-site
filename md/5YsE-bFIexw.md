## TL;DR
Ben Thompson explores how writing things down—from David Allen's Getting Things Done methodology to markdown files used by AI models and agents—serves as the foundational mechanism for expanding human and artificial intelligence, arguing that while AI can simulate memory and workflows, true volition and moral intent remain uniquely human.

## GTD, External Memory, and Personal Productivity
- **The RAM Analogy:** David Allen’s *Getting Things Done* posits that human short-term memory acts like computer RAM, prone to overloading when cluttered with open, unorganized loops.
    - *Ben Thompson's Experience:* Struggled to maintain software implementations like OmniFocus until hiring an assistant to manage his inbox and task lists, effectively outsourcing his external memory to free up mental space for writing.
- **The Role of Software Harnesses:** What made Claude Code powerful in early 2025 was not just the model, but its "harness"—an entire workflow centered on writing copious notes in markdown files.
    - *Function:* These files act as external memory, read into context at any time to keep the model on task and simulate continuous learning despite frozen model weights.
