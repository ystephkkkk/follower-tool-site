## TL;DR
Microsoft and Nvidia unveiled a major evolution in personal computing centered on "hybrid intelligence," combining local Nvidia RTX Spark silicon, Windows ML runtimes, and cloud models to enable secure, autonomous AI agents directly on Windows. The collaboration introduces groundbreaking OS primitives like Micro Virtual Containers (MXC) and Open Shell integration to govern local agents safely while running demanding developer, creative, and enterprise workloads locally.

## Hybrid Intelligence Architecture & Models
* **Core Components:** **Pavan** (Microsoft) highlighted that Windows hybrid intelligence leverages intelligent model routing, performant runtimes, and highly capable local models.
* **Model Quantization Feats:** 
  * **MAI Code 1.1 Flash:** A 130B+ parameter coding model quantized to 3-bit (reducing size by ~80% while retaining quality) with a 256K context window running locally on device.
  * **Nvidia Nemotron:** A 70B+ parameter model quantized to 2-bit, using just over 20GB of memory.
  * **DeepSeek V4 Flash:** A 284B parameter model quantized down to 1.6 bits, fitting into 60GB of memory and outperforming coding/reasoning benchmarks.
* **Runtime & Ecosystem Support:** **Windows ML** is evolving to natively support `Llama.cpp` on day one, giving developers open-source model flexibility across GPUs, CPUs, and NPUs.

## OS Security & Agent Primitives (MXC)
* **Micro Virtual Container (MXC) Integration:** **Satya Nadella** (Microsoft) and **Jensen Huang** (Nvidia) detailed MXC as a fundamental OS primitive for agent containment, operating at the micro-VM, VM, and Windows session levels.
* **Observability and Governance:** **Satya Nadella** emphasized that agent security requires distinct agent identity tracking, complete audit trails of agent execution "exhaust," centralized policy setting, and token-spend governance.
* **Open Shell & Agent Gateways:** Native Windows gateways for agents like OpenClaw eliminate the need for manual terminal configurations, allowing everyday users to deploy secure local agents with a few clicks.

## Copilot, Search, and Everyday Workflows
* **Taskbar Search Actions:** Starting this fall on Windows 11 PCs, users can execute thousands of quick actions directly from the taskbar search (e.g., dark mode, do not disturb, microphone volume sliders, window arrangements, and sending text messages) as fast as they can type.
* **Copilot Enhancements:** **Jacob** (Microsoft) demonstrated Copilot's integration with three new pillars:
  * **Local Context:** Grounding over all local PC files (paralleling enterprise WorkIQ).
  * **Local Actions:** Direct execution of file manipulation and settings changes under user permission.
  * **Local Models:** Offloading tasks to on-device models to save cost and preserve privacy.
* **Autopilot & Automated Workflows:** Demonstrated tax-gathering automation that aggregates local/cloud files, renames documents using local models, and zips them into a single archive securely.

## Hardware Ecosystem: From RTX Spark to Supercomputers
* **Surface Laptop Ultra:** Introduced by **Pavan** as the most powerful Surface built, featuring up to 128 GB of unified memory, up to 1 petaflop of AI compute, 2.5x the thermal capacity of existing laptops, and maintaining over 99% power on battery.
* **Magnetic Connect:** **Pavan** introduced the world's first built-in magnetic USB-C charging port on Surface Laptop Ultra.
* **Broad OEM Partner Lineup:** RTX Spark laptops will be available for pre-order starting launch day and shipping the following Friday from partners including Lenovo (Yoga 9), ASUS (ProArt P14), Dell (XPS 16), MSI (Prestige N16), and HP (Omnibook Ultra 16).
* **DGX Station for Windows:** Deskside supercomputers bringing data-center performance to enterprise desks, enabling local execution of frontier-class models (e.g., Llama V4 Maverick, Kimi K2.6, DeepSeek V4 Pro) exceeding a trillion parameters.
