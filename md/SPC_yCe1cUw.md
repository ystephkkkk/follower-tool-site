## Pushing the Frontiers of Multimodality and Creative Design

*   **The Odisseo Writing App:** Schirano showcased a real-time autocomplete writing tool called Odisseo. The app integrates OpenAI’s new real-time voice API, allowing users to talk to the computer, capture thoughts instantly, and use GPT-5.5 to autocomplete sentences in real-time.

## Advanced Agentic Workflows and Model Evaluation

*   **Custom Evaluation Frameworks:** When testing new OpenAI models, Schirano evaluates three key dimensions:
    *   **Instruction Following:** Measuring how consistently and helpfully the model adheres to complex guidelines.
    *   **Task Execution:** Gauging the model's actual capability to finish what was requested.
    *   **Agentic Direction:** Testing how effectively a model acts as a "creative director" to coordinate other design or agent models.
*   **Custom Codex Shortcuts:** Schirano uses a series of personalized text expansion shortcuts to direct autonomous, multi-agent workflows within Codex:
    *   `spawn`: Spawns multiple sub-agents to work on a task simultaneously.
    *   `agent`: Directs the model to work autonomously toward a specific goal without stopping until completion.
    *   `PR`: Automates pushing pull requests directly to repositories.
    *   `debug`: Prompts Codex to review all session code to identify potential bugs, regressions, or edge cases.

## Reviving Obsolete Hardware with Codex

*   **The Doodle Jump Clone:** Schirano plugged an old, proprietary security and work device with a small screen into Codex via USB. Without official documentation on the proprietary system, Codex analyzed the device's firmware and built a fully functional *Doodle Jump* clone.
    *   **Undocumented Capabilities:** Codex successfully programmed vertical screen scrolling and mapped button sensitivity for long- and short-presses, despite these features not being listed in the device's API documentation.
*   **Unsupervised Task Alerts:** Because Schirano runs long, unsupervised Codex sessions (sometimes lasting 10 to 30 minutes), he programmed the repurposed security device to serve as a physical notifier. 
    *   **Physical Feedback:** Once a backend task finishes, Codex triggers the device to vibrate on Schirano's desk, allowing him to step away from his workstation while staying informed.

## Scaling MagicPath and the Shift to "Supervision"

*   **The MagicPath Platform:** MagicPath is an infinite canvas where humans and agents design and build software together. Schirano plans to launch version 2.0 of the application soon, noting that development would have been impossible without the power of GPT-5.5.
*   **Force Multiplying Lean Teams:** MagicPath operates with a lean team of only six people. By equipping every employee with Codex and GPT-5.5, the team operates with the velocity of 100 to 200 developers, enabling them to spawn new features in a single day and accelerate user feedback loops.
*   **Everyday Systems Integration:** Schirano uses Codex as an "everyday everything assistant." By linking Model Context Protocol (MCP) to platforms like Stripe and Mixpanel, Codex can automatically pull business data, design investor dashboards, organize local files, clean up old music metadata, and draft Apple Notes.
*   **The Age of Supervision:** Schirano envisions a future of work centered on decentralized agents. Humans will no longer focus on manual execution, but on directing and coordinating AI agents to bring ideas to life.
