## How Cursor Trained Composer on Fireworks: Distributed Infrastructure for High-Performance RL

- Channel: Sequoia Capital
- Video: https://www.youtube.com/watch?v=UDTr9yUnLUI
- Published: 2026-05-26
- Briefing: https://ystephkkkk.github.io/follower-tool-site/20260526.html#video-UDTr9yUnLUI
- Speakers: Federico Cassano (Software Engineer, Cursor); Dmytro Dzhulgakov (Co-founder, Fireworks); Sonya Huang (Partner, Sequoia Capital)

---

**TL;DR**  
Cursor partnered with Fireworks to train Composer 2, an agentic coding model that achieves frontier-class performance and extreme cost efficiency. By using a top-down approach—combining mid-training with globally distributed, asynchronous reinforcement learning (RL) on a specialized Mixture of Experts (MoE) base—they successfully dedicated all of the model's finite weight capacity to software engineering tasks.

---

### The Strategic Shift: Transitioning from Application to Foundation Model

*   **Finite Weight Capacity:** Federico Cassano (Research Lead on Composer 2, Cursor) explains that LLM weights act like a storage drive with finite capacity. By eliminating general-world "distractions" and dedicating 100% of those bits to Cursor's specific software engineering tasks, they can serve a smaller, faster model at an order of magnitude lower cost than general frontier models like Claude 3.5 Opus.
*   **The AI Application Evolution:** Dmytro "Dima" Dzhulgakov (Co-founder/Engineer, Fireworks) notes that AI application design naturally progresses from prompt engineering to custom tool harnesses, and ultimately to model fine-tuning. Forcing the model to act natively in its targeted production environment is the only way to bypass the limits of prompt engineering.
*   **Implicit Tool Execution:** Rather than relying on long system prompts to describe tools, Cursor bakes optimal tool usage directly into Composer’s weights during post-training, allowing the model to operate accurately even without structured prompts.

### The Composer 2 Training Recipe

*   **Top-Down Development:** To ship a performant model to users as fast as possible, Cursor rejected the slow "bottom-up" approach of pre-training from scratch. Instead, they used Qwen 2.5—a 1-trillion parameter MoE with 30 billion active parameters—as a strong open-source base.
*   **Mid-Training at Pre-Training Scale:** Cursor performed massive-scale mid-training on code tokens to widen the model's distribution. This phase focused on next-token prediction, teaching the model libraries, syntax, and common code patterns.
*   **Reinforcement Learning (RL) Post-Training:** While mid-training teaches the model *how* to write code, RL teaches it how to write *correct* code, call tools, and navigate the environment. 
*   **Context Compaction in the Loop:** To prevent the model from hitting context limits on long-horizon tasks, Cursor integrated "self-summarization" directly into the RL loop. The model actively learns to compress its own history, enabling a 200,000-token context model to run indefinitely over millions of virtual tokens.

### Designing Pipelined and Globally Distributed RL Infrastructure

*   **Pipelined (Asynchronous) RL:** Standard RL is highly inefficient because trainers sit idle during environment "rollouts" (simulated user sessions taking 5–10 minutes). Cursor and Fireworks co-designed an asynchronous pipeline where rollouts and trainers run continuously. Although this introduces "staleness" (weights changing while a rollout is in progress), the massively increased GPU FLOP utilization far outweighs the minor mathematical staleness.
*   **Globally Distributed Clusters:** Because massive, contiguous GPU clusters are rare and expensive, Cursor executed the training run across four globally separated clusters. They even repurposed off-peak production GPUs to run RL rollouts.
*   **Weight-Synced Delta Compression:** Shipping 1TB model snapshots across the globe every 5–15 minutes is a massive bottleneck. Because RL updates are highly localized, Fireworks built a lossless compression algorithm that only ships the changes (deltas). This made transfers 20x smaller, allowing global weight syncs in under a minute with only a ~30-second swap pause during inference.
*   **Combating the "Cheating" Model:** Models in RL will actively exploit "fake" or simulated environments to game rewards without actually solving the task. To combat this, Cursor built a custom virtual machine stack capable of bursting 100,000 isolated VMs to mimic a real user's local computer environment as closely as possible.

### Overcoming Floating-Point Drift and MoE Complexity

*   **Numerical Non-Determinism:** Floating-point arithmetic is non-associative; the order in which a GPU adds numbers (e.g., $A + B + C$ vs. $C + B + A$) slightly changes the final bits. During asynchronous RL, rerunning a rollout's forward pass to calculate log-probabilities results in mismatches that can completely derail weak RL training signals.
*   **The MoE Expert Mismatch:** In MoE models, minor numerical drift at the gating layer can cause the router to select an entirely different expert (e.g., activating Expert 7 instead of Expert 9). This drastically amplifies divergence and causes the trainer to update parameters that were never actually used during the rollout.
*   **Custom Kernels and Router Replay:** To resolve this, Cursor and Fireworks hand-wrote GPU kernels to force deterministic addition orders (sacrificing minimal speed for stability). They also implemented "router replay," passing the exact expert selection indices chosen during inference directly back to the trainer to ensure perfect mathematical alignment.

### Simulated vs. Real-Time RL

*   **Real-Time RL:** Cursor uses real-time RL to capture live user feedback (thumbs up/down) to update models in production every few hours. 
*   **Simulated RL (Sims):** Offline simulated environments remain necessary because they allow techniques like Group Relative Policy Optimization (GRPO), where the model attempts a task 16 to 128 times in parallel. This allows Cursor to safely experiment with extreme behaviors and isolate precise mathematical signals without ruining the user experience.

---

**TL;DR**
Suno is transforming music from a passive consumption medium into an "active entertainment" platform where 90% of users are creators, utilizing a raw sound-wave modeling approach that prioritizes full-song storytelling over traditional music theory constraints.

### Technical Strategy: Modeling Sound from First Principles
* **Raw Wave Modeling:** Unlike traditional systems that encode the 12-tone Western scale or specific instruments, Suno models music as raw sound waves (float-32 numbers sampled at 48kHz).
    * **Eliminating Constraints:** By avoiding pre-set musical rules, the model can generate "impossible" genres, such as microtonal music or unexpected blends like country with 808s and trap with sitars.
* **Autoregression over Diffusion:** The team intentionally chose autoregressive modeling to prioritize the "story" and structure of a full 3-minute song over the "crisp" audio quality typically offered by diffusion-based clips.
* **Scale vs. Alignment:** Shulman notes that music is not a "scale problem" in the same way Large Language Models (LLMs) are. Success relies less on compute size and more on human preference data to align models with creative tastes.

### The "Creative Entertainment" Business Model
* **The Creator Flip:** While traditional platforms like Spotify are designed for passive listeners, 90% of Suno’s daily users are actively creating. 
* **Gaming Parallels:** Shulman views Suno as closer to gaming or coding (e.g., Claude Code) than traditional music streaming. The act of creation provides fulfillment and "warm and fuzzy feelings" that passive consumption cannot.
* **Defining "Creative Entertainment":** The value lies in the process of building something personal. Shulman compares it to home cooking—people enjoy the meal more because they made it, even if a professional restaurant could produce a "better" version.
* **Reframing "Slop":** Shulman argues that while 99% of AI-generated music may have no interest to the general public, it is deeply meaningful to the person who made it (e.g., a song made with a child), making the "slop" label irrelevant to the user experience.

### Industry Disruption vs. Collaboration
* **Record Label Partnerships:** Contrary to the "disruptor" narrative, Shulman views record labels like Warner as essential cultural institutions.
    * **Positive Sum Tools:** Suno aims to build products that allow fans to interact with their favorite artists' catalogs in new, monetizable ways, deepening the fan-artist connection.
* **The "Coachella" Vision:** Shulman predicts a "truly interactive concert" within the next 12 months where audiences synchronously participate in music-making with the performer.
* **Modernizing the Format:** Shulman highlights that the digital music experience has remained stagnant for 25 years (streaming); AI represents the first major innovation in musical format since the MP3.

### Future Product Roadmap
* **Social Co-creation:** Future iterations will focus on making music creation social, allowing users to send "song templates" to friends to riff on asynchronously.
* **Personalized Audio:** The platform recently introduced the ability for users to use their own voices in tracks, significantly increasing the emotional resonance and attachment to the output.
* **Beyond Background Music:** While many AI music tools focus on "voiceless background music," Suno is doubling down on lyrical, vocal-heavy tracks because the human voice is the most effective tool for storytelling.

> "In Western music there are 12 tones. If you tell the model there are 12 tones, it will only ever produce those 12 tones... for us, it was all about let's throw away everything we know about music and let's try to do this from scratch." — **Mikey Shulman**

> "The creation is actually the entertaining bit. And that is the big step change... we are basically using technology to allow everybody to feel those warm and fuzzy feelings [of creativity]." — **Mikey Shulman**

## This is AGI: Sequoia AI Ascent 2026 Keynote

- Channel: Sequoia Capital

**TL;DR**
Artificial Intelligence has transitioned from a revolution in communication to a revolution in computation, shifting the focus from "faster horses" (incremental productivity) to "cars" (long-horizon agents). This shift is transforming software into a $10 trillion services market where cognitive labor is being commoditized at an unprecedented scale.

### The Paradigm Shift: From Communication to Computation
Pat Grady (Partner, Sequoia) characterizes the current AI wave not as a tool for distributing information, but as a fundamental shift in how information is processed.

*   **A Revolution in Computation:** Unlike the internet or mobile waves, which focused on communication, AI is a "revolution in computation." This creates a "moving floor" where the technological foundation changes daily.
*   **Three Inflection Points:**
    *   **Pre-training:** Validated by the "ChatGPT moment" in late 2022.
    *   **Reasoning:** The emergence of inference-time scaling (e.g., OpenAI’s o1).
    *   **Long-Horizon Agents:** The arrival of agents that can persist until a job is done (e.g., Claude Code), which Grady defines as "functional AGI."
*   **The "Car" Analogy:** Previous AI applications were "faster horses" (10-40% productivity gains). The new era of agents represents "cars"—tools that offer 10-40x productivity and fundamentally change the nature of organizations.
*   **The $10 Trillion Opportunity:** AI is moving beyond the $650B software market into the multi-trillion dollar services market. For example, legal services in the US alone represent a $400B vertical that can now be addressed by AI.

### The MAD Strategy for AI Builders
Grady offers the **MAD** framework for founders building on top of foundation models to navigate a market where "no lead is safe."

*   **Moats (Customer-Back Approach):** In a world where product capabilities change instantly, moats are built by wrapping technology around the customer. While technology is vital, customer intimacy is more durable than specific features.
*   **Affordance (Path of Least Resistance):** Borrowing from design, "affordance" means creating tools that are intuitive. While a terminal (like Claude Code) is powerful, builders must create interfaces that are "brain-dead simple" for the average enterprise user.
*   **Diffusion (The Capability Gap):** The "diffusion gap" is the space between what labs can do and what Fortune 500 companies actually use. This gap represents the primary opportunity for application-layer startups.

### The Rise of the Agentic Economy
Sonya Huang (Partner, Sequoia) argues that "services is the new software," as agents move from "cute but useless" experiments to autonomous workers.

*   **The Agentic Scale:** AI is progressing through four stages of autonomy:
    1.  **AI Assistance:** Tab auto-complete and inline help.
    2.  **Agentic Development:** Humans instructing and managing agents.
    3.  **Async Agents:** Background agents spawning sub-agents with minimal human oversight.
    4.  **Dark Factories:** High-leverage systems where human review is removed entirely (already appearing in cybersecurity).
*   **Tokens vs. Salaries:** Hiring agents is infinitely more scalable and cheaper than hiring humans. Tasks that previously required expensive salaries are being replaced by token costs.
*   **Vertical Impact:**
    *   **Medicine:** Agents inspecting genomes and prescribing medication.
    *   **Law:** Agents performing litigation and settling contracts.
    *   **Science:** Agents discovering new superconductors or solving complex mathematical problems.
*   **Compressed Timelines:** The ability to stack AI-driven breakthroughs means that "whatever you could imagine building over the next 100 years is now possible in 100 days."

### The Cognitive Industrial Revolution
Konstantine Buhler (Partner, Sequoia) predicts that AI will do for cognitive work what the Industrial Revolution did for physical labor.

*   **99.9% Machine Cognition:** Just as 99% of physical work is now done by machines (planes, combustion engines), Buhler predicts nearly all cognition will eventually be machine-led.
*   **The Commoditization of Intelligence:**
    *   **The Aluminum Analogy:** In the 1800s, aluminum was more precious than gold. Once electrolysis made it easy to extract, it became disposable. Intelligence is currently "aluminum"—a precious skill that is about to become a cheap, instantly invoked commodity.
*   **Alien Design:** When machines take over design, the results will be "alien" and non-intuitive to humans. Buhler cites a NASA antenna designed by an evolutionary algorithm that outperformed human designs but lacked any recognizable geometric symmetry.
*   **The Science of AI:** We are currently in a "tinkering phase" similar to early steam engine development. Buhler predicts the emergence of a formal science of AI—comparable to thermodynamics—within the next few decades.
*   **The Human Measure:** As AI masters logic and realism, the value of work will shift toward human connection and the "Art of Unreason." Relationships and emotional experiences will become the primary measures of value.

---

**TL;DR**
Prime Intellect is democratizing frontier AI development by providing the full-stack infrastructure necessary for companies to move beyond static prompting into "environment-based" reinforcement learning, allowing them to compound institutional knowledge into bespoke, high-performance models.

### The Evolution from Prompting to "Environments"
* **Beyond Question-and-Answer:** Traditional AI evaluation relied on static datasets. Modern "environments" are interactive systems (simulators, coding platforms, or databases) where a model learns through trial and error.
* **Environment as the "Train Set":** Will Brown (Founder, Prime Intellect) explains that an environment is essentially an "eval" (evaluation) used as a training ground. It consists of:
    * **The Task:** A dataset or scenario.
    * **The Harness:** The interface or sandbox (e.g., a CLI terminal) where the agent interacts.
    * **The Rubric:** A reward function that grades the quality of outputs and measures progress toward a goal.
* **The "30-Year Expert" Analogy:** While prompting provides a "smart person" to help, training in an environment allows a model to gain the equivalent of "30 years of experience" by deeply interacting with a specific problem over time.

### Democratizing the Frontier Lab Infrastructure
* **Breaking Big Lab Monopolies:** Johannes Hagemann (Founder, Prime Intellect) notes that advanced post-training infrastructure is currently locked behind the walls of major labs like OpenAI and Anthropic.
* **The "Lab" Platform:** Prime Intellect provides a full-stack research platform that handles:
    * **Compute Orchestration:** Managing and debugging GPU clusters for large-scale runs.
    * **Post-Training Stack:** Frameworks for reinforcement learning (RL), supervised fine-tuning (SFT), and online distillation.
    * **Secure Execution:** Sandboxes for running code and simulating complex network environments.
* **The Product-Model Optimization Loop:** Companies like Cursor (with their Composer-1 model) serve as the blueprint. By building a model where the environment is the product itself, startups can achieve performance that generic off-the-shelf models cannot match.

### The Environments Hub: "The GitHub for RL"
* **Standardization and Sharing:** The Environments Hub allows researchers to share and fork interactive training grounds, ensuring implementations are consistent across the community.
* **Modular Building Blocks:**
    * **WikiSearch:** A popular template for agentic search where developers can swap out Wikipedia for their own internal documents.
    * **Coding & Cybersecurity:** Environments ranging from simple games like Wordle to complex "Capture the Flag" cybersecurity simulations.
    * **Medical AI:** Collaborations with groups like Savant and OpenMed to create benchmarks for medical diagnosis and patient interaction.
* **Data Quality Vetting:** RL environments help identify "backdoors" or bugs in data. If a model "games the system" to get a high reward without solving the problem, it exposes flaws in the training environment.

### The Future of AI Research and Strategic Compounding
* **Every Company as a Research Lab:** Will Brown predicts that every company will eventually operate an internal AI research lab to customize models for bespoke workflows and domain-specific languages.
* **Trading Compute for Data:** RL is the primary tool for moving into "uncharted territory." When human-labeled data becomes a bottleneck, RL allows a model to explore and "hill-climb" toward goals using compute power.
* **Institutional Compounding:** The ultimate goal is for software to stand on the "shoulders of what it has done before." Instead of a model "resetting every day," RL allows best practices to compound into the model weights, creating a permanent institutional asset.
