## Why The Harness Matters More Than The Model | YC Paper Club

- Channel: Y Combinator
- Video: https://www.youtube.com/watch?v=n9xKblqyQ28
- Published: 2026-09-07
- Briefing: https://ystephkkkk.github.io/follower-tool-site/20260907.html#video-n9xKblqyQ28
- Speakers: Guillermo Rauch (CEO, Vercel); Suhail Doshi (Founder, Playground); Harjun Bhagat (Research Engineer, Y Combinator)

---

**TL;DR:** The harness—the layer between an LLM and the world providing persistent state, tools, and compute—matters more than the model weights alone, enabling the same model to jump from 30% to 95+% on benchmarks like ARC-AGI simply through improved scaffolding. This briefing covers the evolution of static vs. self-improving harnesses, open-source personal AI stacks, and internal production agent deployments.

### Evolution & History of AI Harnesses
- **V0 Zero Harness (2019):** Basic GPT-2 era setups with fixed personas, prompt text, and end-of-sequence loops without tool calling or skill persistence.
- **Static Harness Era (V1):** Added context innovations (few-shot prompting, chain-of-thought compute distribution), action spaces (Python code execution, tool calling via JSON), and memory/skill abstraction.
  - **Notable V1 Frameworks:** Voyager (skill distillation via Minecraft), WebGPT/Toolformer (API usage), ReAct/Self-Refine/Reflection (multi-agent feedback loops), and Recursive Language Models (RLMs).
- **Self-Improving Harness Era:** Transitioning from static system prompts to architectures where the harness itself learns and modifies its components.
  - **DSPY:** Uses genetic programming and search over a train set to automatically discover optimal system prompts via CRUD operations.
  - **Darwin Machines & Meta-Harnesses:** Allow an agent to modify its own harness code and system prompts, maintaining an archive of agents evaluated against fitness functions.

### Prime Agent: A Self-Improving RLM Harness
- **First-Principles Expressibility (Seth Karten):** Views the raw LLM as a sequential processor (akin to a Turing machine), while the harness turns it into a Von Neumann computer capable of read/write operations on external memory.
- **Context Management Architecture:** Organizes memory into a tiered cache:
  - **L1 Cache:** Model weights (fastest retrieval).
  - **L2 Cache:** Active input context, compaction history, and live interactive loops (IPython/RAM).
  - **L3 Cache:** Dispatch state, file systems, and programmatic sub-agents.
- **Persistent Daemon & Inter-Agent Messaging:** Runs in the background even after closing the terminal session, allowing agents in a "nuclear family" setup (parents, children, siblings) to message each other directly and share context.
- **Benchmark Performance:** Using the responses API and general system prompts, Prime Agent achieved **95.5%** on ARC-AGI with Claude Opus and **78%** with GPT Soul, outperforming several default commercial coding agents while maintaining a favorable cost-to-performance ratio.
- **Long-Horizon Runs:** Successfully executed a 7-day factorial run using **633 agents** across **23 million output tokens** to drive technological progression along a tech tree without getting stuck.

### Open Jarvis: Running Personal AI On-Device
- **Cost and Privacy Imperative (John Sadvilon):** Most personal AI remains cloud-bound, generating thousands in yearly API costs, privacy risks, and high energy consumption. Open Jarvis aims to run model inference, agent execution, memory, and learning entirely on-device.
- **Local Model Viability:** Local LLMs (such as Qwen 3.8 27B) are only 6 to 12 months behind frontier models, closing the performance gap aided by new personal accelerators from Apple (Mac Mini) and Nvidia.
- **The 5-Core Primitive Spec:** Simplifies local stacks into five abstractions: Intelligence (LLM), Engine (Ollama, llama.cpp, SGLang), Agentic Logic, Tools/Memory (MCP protocol), and Optimization/Learning.
- **Cloud-Optimized Local Stacks:** Uses cloud LLMs (like Opus 5 or GPT-5.6 Soul) to automatically diagnose, propose changes to, and optimize local LLM configurations without incurring cloud inference costs at runtime, achieving **800x lower cost** and reduced latency.

### QM: YC's Open-Source Agent Harness for Work
- **Internal Deployment (Josh & Regan):** QM provides every YC employee with a customizable assistant available via Slack or web UI, handling tasks like email triage, legal/finance workflows, document editing, internal database queries, and web app creation.
- **Architectural Shift:** Unlike OpenClaw or Hermes agents where the agent is trapped inside a dedicated VM computer, QM offloads conversation state and context into **Postgres**, centralizing memory across the company.
- **Thin Harness Philosophy:** Keeps the harness extremely thin around three core tools: remote sandbox execution, reading/writing from object storage, and publishing internal apps.
- **Overcoming Agent Limitations:** 
  - **Grind Tools / Budgets:** To combat agents giving up too early on complex research, QM sets clock-time or token-spend minimums (e.g., forcing agents to work for a couple of hours).
  - **Social Context Deficits:** Addresses the fact that agents struggle with social contexts and leak privileged information by leaning on YC's existing fine-grained permission systems.

### Predictions & Forward Calls
- **Device Inference Shift:** "A huge proportion, maybe even a majority, of people's daily inference calls will move to local devices and on-prem workstations as accelerators and local LLMs continue to improve" — John Sadvilon.

### TL;DR
Startups today are tackling significantly more ambitious problems—such as curing cancer and launching intercontinental cargo rockets—while the core mechanics of building a company and the psychological profile of great founders have remained fundamentally unchanged over Y Combinator's 21-year history.

### Evolution of Startups and Ambition
* **Supposedly "Good Old Days":** Critics often claim YC has lost its edge since 2008, but early iconic companies like Reddit were far less serious than current batch companies building intercontinental ballistic cargo systems or tackling cancer.
* **Frighteningly Ambitious Ideas:** The 2012 essay concept of a "new Google" manifested via OpenAI, which bypassed head-on search competition by making obsolete the traditional web-page discovery model in favor of direct information delivery.
* **Serious Healthcare Ventures:** Current YC batches feature multiple diverse approaches to curing cancer, ranging from vaccines to on-demand cancer research ("death of a thousand cuts"), mirroring how YC alumnus Sid Sijbrandij of GitLab successfully attacked his own cancer.

### Founder Psychology and Formidability
* **Inborn Drive:** Great founders possess an innate, formidable drive that cannot be easily manufactured; the rare exceptions are young founders who have merely been trained by pushy parents or environments not to show their ambition.
* **Real-Day Motivation:** While billionaires-in-the-making, founders are driven day-to-day by immediate survival fears—such as a crashing server or an engine falling off a model train set—rather than financial wealth.
* **The "Formidable" Definition:** Coined from Jessica Livingston and Maya's private language, a formidable founder is simply someone who "gets what they want in any situation," aligning perfectly with investor interests.
* **The Anti-Credential:** Treating startups as a resume badge or cool credential is a severe mismatch, akin to applying to Harvard and being forced to study theoretical physics with no easy majors available.

### AI Surprises and the Definition of AGI
* **The Inverted AI Trajectory:** Rather than starting with a perfect fly brain and working up to humans, AI development started with a full-human but deeply flawed baseline ("an undergrad trying to bluster his way through a paper") and is working toward perfection.
* **The Jagged Frontier:** AI exhibits uneven capabilities, effortlessly solving famous open math problems while struggling with basic real-world tasks like restaurant opening times.
* **The Turing Test Redefined:** AGI is no longer viewed as a clear-cut finish line, but rather as a "smear" with certain AI capabilities well across the line while others lag behind.
* **GPU and Token Economics:** While salaries used to be the primary startup cost, companies now face massive token and GPU infrastructure bills, though inference costs consistently drop dramatically over time.

### Y Combinator Origins and Structure
* **Accidental Beginnings:** YC started out purely as an angel firm using standardized paperwork, initiating batches specifically to function as an alternative summer job for undergraduate students.
* **Batch Advantages:** YC provides crucial isolation relief by giving founders colleagues to work alongside, technical problem-solving support from peers, and the "YC GDP"—an immediate cohort of early adopters.
* **Growth and Scaling:** Despite growing from 40 startups in the early days to massive current batches, YC preserves the intimate environment by organizing companies into pods of roughly 70 startups.

### TL;DR
The White House strongly supports open-source AI as essential for U.S. technology leadership, while prioritizing regulatory clarity and a single national standard to help startups avoid a restrictive state-level patchwork. Michael Kratsios and Luther Lowe outline the federal strategy for science, technology, and AI at Startup School 2026.

### Washington's AI Strategy & Open Source
* **Commitment to Open Source:** The White House's national AI strategy (co-authored by Michael Kratsios, David Sacks, and Secretary Rubio in July 2025) explicitly commits to maintaining a vibrant ecosystem of both closed and open-source models.
* **Open Weights and Rumors:** Speculative executive orders restricting open-source models are countered by active administration policy; Kratsios praised industry advocacy—including open letters organized by Y Combinator—for providing the direct feedback loop necessary for sound policymaking.
* **Federal-Private Dialogue:** Government policies rely on real-time input from the startup community, tech ecosystems, and financial institutions to prevent decisions made in a Washington vacuum.

### Regulating a Fast-Moving Technology
* **Avoiding EU-Style Red Lines:** The White House explicitly avoids setting firm red lines or hard compute thresholds that fail to stand the test of time, citing the EU AI Act (passed before the invention of ChatGPT) as a cautionary tale of rigid regulation.
* **National Standards vs. State Patchworks:** A key priority for President Trump is preempting state-level laws to establish a single national framework for AI, shielding resource-constrained startups from navigating conflicting state regulations.
* **Born-Free vs. Born-in-Captivity Tech:** Regulation is categorized into "born-free" domains (like the early internet) which require preservation from over-regulation, and "born-in-captivity" domains (like commercial drones and supersonic flight) where targeted regulatory barriers and permit processes must be actively dismantled.

### Washington Perspective vs. Silicon Valley Realities
* **Balancing Competing Concerns:** Washington policymakers must simultaneously weigh the broader public perception of AI, data center expansion in local communities, healthcare applications, and labor market impacts alongside raw compute demand.
* **Supporting "Little Tech":** The administration acknowledges the dominance of large tech players and utilizes traditional stakeholder mechanisms, Requests for Information (RFIs), and federal antitrust enforcement (such as ongoing DOJ and FTC cases against Google, Apple, Facebook, and Amazon) to ensure smaller startups retain a seat at the table.
* **Intellectual Property and Creators:** While direct model outputs (e.g., generating unauthorized trademarked assets like Mickey Mouse) remain restricted by statute, the White House prefers to let market-driven revenue-sharing agreements and licensing deals mature organically rather than over-legislating the space prematurely.

### The Inside View of Federal Policy & Science
* **Federated Decision-Making:** Technology policy is distributed across multiple agencies (defense, health, energy, science); the White House acts as the central convening authority to align competing agency equities before policy is executed.
* **The "Science: A New Golden Age" Report:** Released in early 2026, this report re-evaluates the post-WWII Vannevar Bush model, noting that R&D funding has inverted—with the private sector and philanthropy now driving roughly 70% of research compared to the federal government's 30%.
* **Autonomous Scientific Discovery:** The report emphasizes that artificial intelligence will fundamentally transform material science, pharmaceuticals, and chemistry via autonomous cloud labs and robotic experimentation loops.

### Predictions & Forward Calls
* **AI in Science (Michael Kratsios):** Scientists in material science, pharmaceuticals, and chemistry will conduct research dramatically differently because of artificial intelligence **within 2 to 3 years**.
* **Quantum Computing Goal (President Trump via Michael Kratsios):** The Department of Energy is directed to build a scientifically relevant quantum computer **by 2028**.

### 1. Silicon Valley Culture & Founder Psychology
* **The Cost of Chasing Trends:** Garry Tan reflects on his early career mistakes in 2003—such as joining Microsoft's Windows Mobile team instead of staying with web programming or joining early Palantir founders Joe Lonsdale and Stefan Cohen—attributing those errors to chasing what was "hot" rather than following direct experience and first-principles knowledge.

### The Genesis and Vision of Paper
* **Founding & Team Size:** Paper was started as a solo side project by Stephen Haney out of a love for creative tooling and founder-market fit, and has grown to a team of **12 designers and engineers**.
* **Agent-Native Rendering Engine:** **Stephen Haney** explains that Paper uses HTML and CSS as its actual rendering engine rather than a custom rendering engine.

### Core Features and Demos
* **Paper Shaders:** Fully open-source WebGL animations designed by studying physical paper to model natural randomness.

    * **Real-World Usage:** **Aaron Epstein** notes that Y Combinator uses these shaders for acceptance tickets and Startup School branding.
* **Image Generation & Vectorization:** Paper features an image generation library using four different models simultaneously via a "variety pack," alongside color extraction and vectorization tools.
* **Desktop App & MCP Server:** Built following the December 2025 cloud code explosion, featuring an MCP server that allows agents like Cursor and Conductor to directly render and manipulate frames on the canvas.

* **The Importance of Differentiation:** **Stephen Haney** and **Aaron Epstein** emphasize that using default, unedited AI output makes startups look generic, untrustworthy, and indistinguishable from millions of other projects.
* **Common AI Design Tells:**
    * **Excessive Font Weight & Sizes:** Models over-use bold weights and incorporate 5 to 8 different font sizes.
    * **The "Four Horsemen":** Side-swatches of color on every card, purple gradients, all-uppercase tiny headers with wide letter spacing, and badge pills with unnecessary small icons.
    * **Widgets for Widgets' Sake:** Pointless decorative numbers or small UI elements added merely to fill space.
    * **Default Dark Mode:** Forcing dark mode on every MVP regardless of whether it fits the product.
* **Quick Remediation Rules:** **Stephen Haney** advises designers to pull font weights back to regular or light, restrict type hierarchies to a maximum of **three font sizes**, and ruthlessly delete non-communicative decorative elements.

* **Legion Health Review:** 
    * **Aaron Epstein** notes the original design suffers from generic pill elements and weak alignment, lacking the trustworthy fit-and-finish required for mental health medication management.

### The Era of Personal AGI
- **Redefining AGI:** AGI is not arriving as a singular god in a data center, but as infrastructure diffused through your agent running on your context and doing your work.
- **Rented vs. Owned AI:** Corporate chatbots are rented subscriptions with lobotomized context that reset when you close the tab, whereas personal AGI runs on your infrastructure, reads from your memory, and compounds daily.
- **The Core Equation:** Personal AGI combines a rented frontier model, owned unique context, and a harness (such as OpenClaw, Hermes Agent, Claude Code, or Codex) to create an agent that acts like a fast version of yourself.

### 100x Leverage in Knowledge Work
- **Coding Multiplier:** Programming output has scaled drastically; Garry Tan estimates operating at roughly 400x the code volume of 2013 (or a strict floor of 8x to 10x with severe verbosity penalties).
- **Portfolio-Scale Evidence:** In the Winter 2025 YC batch, a quarter of the companies had code bases that were 95% AI-generated, and those companies are on track to be among the fastest-growing in YC history.
- **Universal Multiplier:** The leverage applies equally to product management, design, and growth by treating AI as a workforce rather than mere autocomplete.

### Architecture of a Personal AI System
- **Memory Limits vs. Capacity:** Human working memory is strictly limited to seven items ($\pm 2$), while an AI agent holds a million tokens (roughly a thousand pages, or three Harry Potter books) and can find a needle in them instantly.
- **The Knowledge Library:** Garry Tan's personal system (GBrain) utilizes a Carpathy-style knowledge wiki with about 220,000 markdown pages, capturing 25 years of diarized life, emails, meetings, and notes.
- **Skill Files:** Markdown instructions in plain English act as employees (e.g., summarizing meeting transcripts, pulling commitments, and cross-checking facts).
- **Latent Space vs. Deterministic Code:** Judgment, taste, and reading user intent belong in latent space (steered by markdown), while arithmetic, SQL queries, and seating charts require deterministic code.

### The Economics and Politics of Skill Files
- **The Revenue Per Head Revolution:** AI-native companies are breaking historical metrics; Emergent (Summer 2024 batch) reached nine figures of revenue in 8 months with only 15 people when crossing $15M ARR, and Retail (Winter 2024) hit $60M ARR with about 40 people.
- **The Career Risk:** Skill files externalize your cognition; if they live in a company's repository under corporate IT policies, your career is extracted when you leave; if they live in your repo, your expertise compounds.
- **The Spinozan Choice:** Comparing the offer to the "thousand gilders" or Heidelberg professorship offered to Baruch Spinoza, Tan warns founders against comfortable arrangements that trade personal ownership for short-term salary and compliance.

### Five-Step Implementation Guide
- **Step 1 — Pick a Harness:** Run an agent locally using OpenClaw, Hermes Agent, or GBrain (available free at `gbrain.io`), or use lighter tools like Codex or Claude Code.
- **Step 2 — Start Your Library:** Create a single folder of markdown files containing notes, projects, and working relationships that only exist in your head.
- **Step 3 — Write Your First Skill File:** Automate your most hated weekly task (expense reports, meeting notes, status updates) by explaining it in plain English to your agent.
- **Step 4 — Wire Up Recurring Jobs:** Schedule background jobs (e.g., 7 AM daily briefings or Friday summaries) so work finishes while you sleep.
- **Step 5 — Skillify Everything:** Never do one-off work; at the end of every task, command the agent to extract and save the process as a reusable markdown file.

- **Garry Tan claims:** Over the next 90 days of implementing the 5-step framework, users progress from a clumsy toy in **Week 1** to a working flywheel by **Week 4**, resulting in a fully functioning personal library and automated workflows by **Week 12**.
