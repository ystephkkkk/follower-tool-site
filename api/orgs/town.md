### TL;DR
Agent-to-agent systems are fundamentally search problems constrained by privacy rather than context length, and building scalable multi-agent architectures requires balancing context access with privacy boundaries. Jean-Denis Greze evaluates five current strategies for crossing information silos and predicts that automated, policy-driven shared spaces will drive the next wave of enterprise AI ROI.

### Reframing Agent-to-Agent as a Search Problem
* **Search over Agent-to-Agent:** Jean-Denis Greze rejects the concept of agent-to-agent interaction, arguing that LLM systems are fundamentally search problems.
    * **Context Window Optimization:** The primary objective is ensuring the right information sits in the context window immediately before a tool call or result generation.
    * **Evolution of Retrieval:** Progression has moved from manual human population (4 years ago) to RAG search tools, and currently to agentic search where agents autonomously navigate content spaces.
* **The Ideal State and the Coase Theorem:** Applying the Coase theorem, Greze posits that an omniscient single agent with access to all world information would produce optimal economic outcomes.
    * **The Privacy Barrier:** The only factor blocking an infinite-context, all-knowing agent is privacy and security, which act as transaction costs.

### Five Strategies for Bridging Information Silos
* **1. Trust Boundary Access:** A shared trust boundary gives an agent access equivalent to a human team member (e.g., an HR agent with access matching the team's most junior employee).
    * *Limitations:* Requires ongoing human oversight and merely creates a new silo rather than de-siloing data.
* **2. Privacy-Preserving Custom Tools:** Designing tools that trade raw data access for specific, sanitized outputs (e.g., returning a relationship strength score instead of raw email contents).
    * *Limitations:* Manual to design, requires explicit user explanation, and does not automatically improve as underlying model intelligence increases.
* **3. Shared Silos and Automated Sweepers:** Creating collective spaces (like shared wikis or code repos) where data naturally accumulates.
    * **Sweeper AI:** An agent operating inside a private silo that uses a policy to automatically push non-sensitive information into company-wide shared spaces.
* **4. Human-in-the-Loop Conduits:** Traditional agent-to-agent architectures where one agent asks another agent's human owner for permission to access information.
    * *Limitations:* Highly inefficient in larger organizations, leading to notification fatigue when requests are broadcast to dozens of employees.
* **5. Black Box Access with Selective Approval:** An omniscient LLM searches across all private silos blindly, determines the exact source of needed data, and prompts *only* the specific data owner for approval right before the tool call.
    * *Risks:* Requires high trust in the black box and carries risks of inadvertent data disclosures (e.g., accidentally revealing job interviews via recruiter contacts).

### Key Operational Risks and Challenges
* **Prompt Injection and Poisoning:** Open shared silos are vulnerable to prompt injection attacks and corrupted data (e.g., an LLM hallucination persisting indefinitely in a shared knowledge base).
* **Compliance and Auditability:** Enterprises require logging, reversibility, and CISO-level audit trails, preventing true black-box opacity.
* **False Disclosures:** Without proper human-in-the-loop safeguards, wrong disclosures can lead to customer lawsuits or employee terminations.

### Predictions & Forward Calls
* **Near-Term Enterprise Adoption:** Within the next 6 months, smaller high-trust companies (10–50 employees) will widely adopt automated policy-driven LLMs to surface private information into shared spaces.
* **Evolution of Auto Mode:** Just as coding workflows shifted from mandatory approval to Anthropic's "auto mode," agent-to-agent systems across information silos will increasingly default to automated disclosure for low-sensitivity data as models and policy-encoding improve.
