### New Products: Daybreak Red Team & Defense Factory
* **Daybreak Red Team (Early Access):**
  * **Purpose:** An offensive security platform using frontier cyber models and an automated harness to deliver superhuman pen testing at the scale of continuous scanning.
  * **Key Capabilities:** Assembles tailored campaigns using source code, Slack context, and staging environments to uncover exploit chains (e.g., stored SQL injection leading to multi-tenant data exposure) and generate minimal patch recommendations.
  * **Design Partners:** DoorDash, Vanta, Harvey, and others.
* **Daybreak Defense Factory:**
  * **Purpose:** Automates the defensive loop to find, validate, deduplicate, and fix vulnerabilities continuously.
  * **Key Integrations:** Supports OpenAI's first-party scanner alongside third-party tools like **Wiz**, **Sneak**, and **Daybreak Red Team**.
  * **Cloud Development Environments:** Spins up reproducible CDEs where agents pull code, dependencies, and tools to run, validate, and test patches before raising merge-ready pull requests.
  * **Automation Toggles:** Enables secure code review, continuous monitoring on commits, and deeper daily scans to block pull requests introducing critical security issues.

### Real-World Case Studies & Enterprise Metrics
* **Patch the Planet Initiative:** Funded security researchers to land patches, including identifying the PHP-to-shell vulnerability.
* **Firefox Security Campaign:** 
  * Used **GPT-4 Cyber** to scan the codebase despite prior testing by multiple labs.
  * Found and reproduced **81 previously unknown high-severity vulnerabilities**.
  * Uncovered new attack paths for **30 known issues** previously considered low/medium severity and non-exploitable, re-prioritizing them to high severity.
* **PHP-to-Shell Vulnerability Analysis:** 
  * The underlying flaw existed for **13 years**. Kalif established exploitability using OpenAI cyber models.
  * OpenAI used models for variant analysis, adversarial patch testing, and evaluating mitigation options, compressing weeks of work into a few days.
* **Linux Kernel Campaign:** 
  * Tested on Linux (**40+ million lines of code**) using an autonomous discovery, exploitation, and patching pipeline.
  * **GPT-6 Cyber Run:** Validated and generated patches for **nearly 1,000 local privilege escalation (LPE) vulnerabilities** (over 5x the LPEs found by 5.6 three months prior).
  * Uncovered **10 novel Linux exploitation techniques** totally new to OpenAI and external parties (published as *"1,000 Fewer Paths to Root"*).
* **Intuit (Night Falcon):** Combines vulnerability discovery, data flows, and agents; reports that **87%** of closed findings were confirmed vulnerabilities that got fixed.
* **Block:** Uses Daybreak models to improve detection engineering and alert triaging workflows.
* **Agentic SOC Performance:** Customers test detection changes against **7 months of production telemetry in under an hour**, saving **600 analyst hours per quarter** on false positive triaging.
* **Sophos:** 
  * **52%** of managed detection and response cases are solved end-to-end by Daybreak agents.
  * Average response time fell from **38 minutes to just 89 seconds**.
