## How To Design In The Agent Era

### TL;DR
Stephen Haney, founder of AI-native design tool Paper, joins YC General Partner Aaron Epstein to demonstrate how Paper uses HTML/CSS rendering to bridge human design taste with agentic workflows, while warning founders against generic AI design "slop."

### The Genesis and Vision of Paper
* **Founding & Team Size:** Paper was started as a solo side project by Stephen Haney out of a love for creative tooling and founder-market fit, and has grown to a team of **12 designers and engineers**.
* **Agent-Native Rendering Engine:** **Stephen Haney** explains that Paper uses HTML and CSS as its actual rendering engine rather than a custom rendering engine.
    * **Developer & Agent HandOff:** This constraint-free system creates a seamless handoff for both human developers and AI agents, because agents natively understand HTML/CSS from their training data.
    * **Token Efficiency:** This approach saves tokens, runs faster, and produces fewer hallucinations.
* **The New Agent Stack:** **Stephen Haney** describes the modern builder setup as combining Cursor, Claude Code, and GitHub with Paper acting as the visual interface to communicate with agents.
* **Company Traction:** According to Ramp credit card subscription data cited by **Aaron Epstein**, Paper is the first company since Figma to make a measurable dent in the design tool market, growing rapidly and ranking alongside Sketch.

### Core Features and Demos
* **Paper Shaders:** Fully open-source WebGL animations designed by studying physical paper to model natural randomness. 
    * **Marketing Strategy:** **Stephen Haney** notes that Paper treats its shader library and custom fonts (like the upcoming **Paper Mono**) as its marketing budget instead of buying traditional ads.
    * **Real-World Usage:** **Aaron Epstein** notes that Y Combinator uses these shaders for acceptance tickets and Startup School branding.
* **Image Generation & Vectorization:** Paper features an image generation library using four different models simultaneously via a "variety pack," alongside color extraction and vectorization tools.
* **Desktop App & MCP Server:** Built following the December 2025 cloud code explosion, featuring an MCP server that allows agents like Cursor and Conductor to directly render and manipulate frames on the canvas.
* **Paper Snapshot:** A Chrome extension allowing users to pull live websites directly into the Paper canvas as editable layers instead of taking static screenshots.

### Deconstructing AI Design "Slop"
* **The Importance of Differentiation:** **Stephen Haney** and **Aaron Epstein** emphasize that using default, unedited AI output makes startups look generic, untrustworthy, and indistinguishable from millions of other projects.
* **Common AI Design Tells:**
    * **Excessive Font Weight & Sizes:** Models over-use bold weights and incorporate 5 to 8 different font sizes.
    * **The "Four Horsemen":** Side-swatches of color on every card, purple gradients, all-uppercase tiny headers with wide letter spacing, and badge pills with unnecessary small icons.
    * **Widgets for Widgets' Sake:** Pointless decorative numbers or small UI elements added merely to fill space.
    * **Default Dark Mode:** Forcing dark mode on every MVP regardless of whether it fits the product.
* **Quick Remediation Rules:** **Stephen Haney** advises designers to pull font weights back to regular or light, restrict type hierarchies to a maximum of **three font sizes**, and ruthlessly delete non-communicative decorative elements.

### Live Redesigns: Legion Health, Sciteex, and More
* **Legion Health Review:** 
    * **Aaron Epstein** notes the original design suffers from generic pill elements and weak alignment, lacking the trustworthy fit-and-finish required for mental health medication management.
    * **Live Fix:** Using Paper Snapshot and conductor, **Stephen Haney** generates multiple layout variations, cleans up font weights, and removes overlapping text elements.
* **Sciteex Review:**
    * **Aaron Epstein** points out that the field infrastructure platform's value proposition is buried below the fold, overshadowed by heavy purple glows and vibe-coded elements.
    * **Live Fix:** Simplifying the layout to three font sizes and removing bold weights immediately elevates the design's perceived trustworthiness.
* **The New Curation Workflow:** **Stephen Haney** explains that builders can leave comments on a design, let agents run overnight generating hundreds of variations, and curate the best ideas into a unified final product.

### Founder Lessons and Future Outlook
* **Previous Ventures:** **Stephen Haney** previously founded Modulz (focused on design-to-dev handoff) and created Radix UI, which was eventually sold to Work OS.
* **Operational Philosophy:** **Stephen Haney** stresses focusing on bottlenecks first, avoiding over-complicated strategies, and maintaining a strict rule of **talking to a user every single day** for the first year (a culture now instilled across Paper's entire 12-person team).
* **Roadmap:** Paper's upcoming focus for the next **6 months** includes building out table stakes features like components, comments, and prototype organization tools for designers using vibe-coding playgrounds.
