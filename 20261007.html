TL;DR

OpenAI introduced OpenClaw (OC) and OpenClaw Enterprise (OCE)—an open-source platform and enterprise control plane for multi-tenant, multiplayer AI agents that collaborate in real time with developer teams. The project scales agent operations through secure sandboxing, automated background loops, and shared workspaces while expanding the open-source Codex ecosystem.

Evolution of Developer Workflows and Multiplayer Agents

  • From CLI to Distributed Agent Workloads:
    • Peter described the progression from terminal/CLI sessions last year to Codex Desktop, which enabled running large numbers of concurrent sessions with inline code review and visualization.
    • Running multiple parallel agent experiments required scaling up to 6–10 DevBoxes and cloud test runners ("Grabboxes") to handle disk space and compute load.
  • Overcoming the "Meat Proxy" Bottleneck:
    • Initially, one developer acted as the sole human interface ("meat proxy") passing messages back and forth to AI agents.
    • Moving development of OpenClaw directly into OC enabled multiplayer agent sessions, allowing entire teams to see, audit, and prompt each other's agent sessions in real time instead of relying solely on traditional pull requests.
  • The OpenClaw Foundation:
    • OpenClaw is an open-source platform for persistent agents owned by the OpenClaw Foundation, an independent nonprofit supported by OpenAI.

Collaborative Team Workspaces and "Jellyware"

  • Shared Team Servers:
    • Servers function as shared places rather than static apps, allowing teammates with identical access to observe, join, and prompt active agent sessions to prevent conflicting changes.
  • Jellyware Dashboards:
    • Teams build and iterate on live dashboards, CI metric trackers, community activity monitors, slop meters, and Discord meeting summaries using simple natural language prompts.
  • Continuous Loops vs. Defined Goals:
    • Continuous Loops: Automated monitoring loops scan Discord, Twitter, and GitHub, spin up test boxes to reproduce reported errors, apply fixes, and have secondary agents review the work before merging. A performance update loop runs daily snapshots against server releases to detect regressions.
    • Goals: Long-running targets, such as migrating a codebase from synchronous SQLite to async database access, which has been running for 18 days and landed over 100 PRs.

OpenClaw Enterprise (OCE) and Security Architecture

  • Kevin Lin's Enterprise Overview: Kevin Lin, who leads OpenClaw Enterprise at OpenAI, announced the open-sourcing of OCE as a vendor-neutral open-source control plane donated to the OpenClaw Foundation (co-developed with partners like Red Hat and NVIDIA) to provide multi-tenancy, governance, and security boundaries.
  • Four Security Fundamentals:
    • Hard Workload Boundaries: Deterministic code runs in a separate container and separate cluster from where the agent executes, preventing agents from altering their runtime.
    • Granular Sandboxing: Controls network access, file write permissions, and repository push targets to limit agent capabilities.
    • Model-Based Auto-Reviews: Uses auto-review (a feature in Codex and OpenClaw) powered by a secondary model to evaluate agent actions and block potentially dangerous executions.
    • Dedicated Service Accounts: Agents operate under their own independent service accounts and configurable connectors rather than impersonating human users, allowing independent auditing and deactivation.
  • Internal Scale:
    • Internal deployments at OpenAI have scaled to over 400 active Claws operating around the clock for code fixes, experiments, data analysis, and security escalation.
  • Presets and Integrations:
    • Enterprises use configurable presets (agent bundles) to launch agents like "Fred" or "Cooper" with pre-configured tool access, such as read-only codebases, Linear roadmap tracking (with team approval gates), and Slack integrations.

Ecosystem Support and Security Initiatives

  • Codex Open Source Program: OpenAI expanded the open-source program for Codex to ensure broader access to AI tools.
  • Patch the Planet: Partnering with security groups such as Trail of Bits to improve open-source security infrastructure and address fundamental vulnerability classes.

TL;DR: OpenAI announced Codex Cloud, Spaces, Dots, and integrations with Slack and Microsoft Teams at DevDay 2026, allowing developers to run long-term AI agents in cloud environments without tying up their local laptops. Dominik demonstrated new capabilities including mobile source editing, Tailscale and OIDC networking support, an overhauled code review workflow, terminal voice mode, and a unified web interface.

Codex Cloud & Infrastructure

  • Codex Cloud Environments:
    • Allows running tasks on cloud environments that teams have created or by setting up new ones connected to selected repositories.
    • Handles environment preparation automatically by inspecting repositories, identifying dependencies, and writing startup scripts and skills.
    • Features file system snapshotting for faster subsequent task startup and background updates to keep repos current.
  • Network Integration & Security:
    • Tailscale VPN Support: Integrates via auth keys so cloud environments can securely access private resources (such as a local API running on a Raspberry Pi) without exposing them to the public internet.
    • OIDC Support: Enables accessing cloud resources through OIDC.
    • Vault & Sharing Controls: Personal environment variables can be stored in a vault to prevent sharing with the team, and environments can be restricted to individual use or shared across the entire organization.
  • Cross-Device Continuity:
    • Tasks run in the cloud, allowing developers to close their laptops and continue tracking or interacting with tasks via phone or browser.

Team Collaboration & Unified Workspaces

  • Spaces:
    • Serves as a collaborative document space for both human teams and Codex agents.
    • Eliminates the need to copy-paste information back and forth between different docs and agent chats.
    • Example given: Writing an API reference implementation plan, generating system diagrams, embedding task trackers, and having Codex update progress in real time as it executes tasks.
  • Slack and Microsoft Teams Integrations:
    • Brings Codex Cloud environments directly into team chat tools.

    • Pressing the spacebar with two command buttons captures a screenshot alongside metadata, URLs, and below-the-fold content from any application.

    • Unlike local automations that stop when a computer shuts down, dots run continuously in the cloud with their own computer, browser, and file environments.
    • They soak up background context from Slack, email, and browsers without requiring manual heartbeats or markdown vaults.
  • Embodied and Multi-Surface Access:
    • Dots can operate across phones, browsers, and local machines.
    • Users can enable settings allowing cloud agents to use the local machine as a "last mile" of work (e.g., logging into a browser, testing a local app).

2. Voice Integration and Team Collaboration

  • Agentic Voice:
    • Allows two-directional voice interaction on mobile and desktop apps, operating roughly 3 to 4 times faster than typing.
    • Enables messy, unscripted brainstorming sessions that the AI cleans up automatically.
  • Meeting Notes and Team Prompts:
    • ChatGPT meetings transcribe conversations and allow dots to pick up action items and context automatically.
    • Users can prompt agents mid-call to draft blog posts, create timelines, or send Slack messages.
  • Team Tagging:
    • Users can tag their dot in Slack or Teams (e.g., `@Jason dot, please investigate`) to delegate tasks following team design discussions.

3. Organizing Work in Shared Spaces

  • Spaces as Cloud Memory Vaults:
    • Acts as a single source of truth where agents and team members contribute without duplicating work across departments.
  • Agent MD Files and Page Instructions:
    • Directory-based agent MD files guarantee that automated writes remain human-readable with correct citations and formatting.
    • Custom artifacts, embedded HTML, and visualizations can be defined via page instructions to keep team agents aligned.
  • Cross-Departmental Use Cases:
    • *Finance:* Weekly analytics reports updated by cloud agents connected to cloud services.
    • *Engineering:* Organizing pull requests, project scope, and identifying designated DRI (Directly Responsible Individual) pages.
    • *Research:* Tracking long-running experiments.

4. Sharing Results via Plugins and Extensions

  • Plugins and Extensions:
    • Serve as shareable, updatable, and versioned instruction-based plugins distributed widely across teams.
    • Codex app acts as a cockpit; products like the meetings and code review tools are built on these exact plugin components.
  • MCP and WebMCP Integration:
    • Sites can serve Model Context Protocol (MCP) servers with authentication.
    • WebMCP allows the creation of tools that both humans and AI can use simultaneously.
  • Broader Creative and Production Workflows:
    • Used beyond engineering for production shoots (keeping sets updated during breaks) and content planning with creative and marketing teams.

TL;DR

Jeff Harmon shares how founders can find marketing "glitches"—untapped channels of attention—to scale businesses, drawing on his experience building viral ad campaigns for brands like Poo-Pourri and Squatty Potty, and scaling Angel Studios into a top-10 global movie studio doing nearly $500M in revenue.

1. Finding Your "Glitch" in Marketing

  • Definition of a Glitch: Look for areas where you have attention from people that nobody else is paying attention to, functioning as a tactical beachhead for growth.
  • The Ora Brush Origin Story:
    • Jeff Harmon helped a college professor sell a tongue cleaner sitting in boxes in his garage by buying a Facebook page called "Kisses" (1.3M followers) and pivoting it to Ora Brush.
    • Initial ads failed because they focused on product details rather than the happy ending/benefit for the customer (e.g., kissing without bad breath shame).
  • The YouTube Ad Arbitrage Glitch:
    • Leveraged YouTube's newly launched ad platform to run a $500 script-driven video (using a spoon-scraping bad breath demonstration inspired by an I Justine video) at less than a penny per view.
    • This early-mover advantage yielded a $2-$3 return for every $1 spent on total costs (ads, shipping, product), eventually leading to a $10M company exit.

2. Product Development and the "User Method"

  • Solve Your Own Problems: Follow the "User Method" popularized by Jeff Schwarting—most top businesses are built by founders solving personal problems (e.g., Airbnb founders trying to pay rent).
  • Dr. Bob's Motivation: The inventor of Ora Brush was a mission president in the Philippines trying to solve horrible breath among his missionaries.
  • Agentic Shopping Opportunities: Shift attention away from Google search and optimize for AI agents (like Grockbot) where shopping happens via direct API integrations without users leaving the AI interface.

3. Crafting High-Conversion, Comedy-Driven Ads

  • The Harmon Brothers Formula:
    • Combine a rigid structure (problem, solution, 3 core elements, credibility, call to action) with professional comedians who understand how to build humor that drives the core message.
    • It is significantly easier to train a comedian to be a marketer than a marketer to be funny.
  • High-Stakes Creative Retreats: Lock creatives, attorneys, and key stakeholders in a cabin for 2–3 days with competing script reads until a winning concept is forged and signed off.
  • Poo-Pourri and Squatty Potty Breakthroughs: Transformed struggling or small-scale products into billion-dollar brands by leaning into absurd, high-contrast juxtapositions (e.g., a cute British girl talking about pooping on a toilet).

4. Disrupting the Movie Business with Angel Studios

  • The Angel Guild Model:
    • Built a community of ~3M members paying $12–$20/month who vote on incoming projects, receive two movie tickets per month, and actively fund/feedback-loop indie filmmakers.
    • Members have paid out $300M in profit shares to filmmakers, with Angel splitting profits 50/50 with creators.
  • The Chosen Pilot Experiment:
    • Bypassed traditional Hollywood gatekeepers by uploading a 19-minute pilot as a skippable YouTube ad, raising $11M from 17,000 investors via $800K in ad spend.
    • The resulting series achieved 200M+ global viewers and seven seasons of production.
  • Viral Stunts and Algorithm Warming:
    • Leveraged Kevin James's face in unlisted social channels and viral art-teacher personas to "warm up" algorithmic facial recognition before launching projects like *Solo Meal* and *Runner* (which secured 100M views via a comedic minivan/Owen Wilson campaign).
    • Executed a Super Bowl stunt by placing Kevin James in a tuxedo surrounded by influencers and cameras in the center of 12 empty seats without any direct commercial messaging.

5. Executive AI Workflows and Economics

  • Personal Vibe Coding: Jeff Harmon uses a personal vibe coder and late-night Claude/GPT prompts running agents overnight to prototype software tools (such as automated movie trailer AB-testing links) before handing them off to the product team.
  • AI Harnesses: Angel Studios utilizes internal brand-guide harnesses hooked into AI coding models to ensure automated output respects company rules.
  • AI and Employment Economics: Dismisses the idea of mass AI-driven unemployment, arguing that when a tool makes teams 10x more effective, businesses expand headcount to capitalize on increased productivity rather than shrinking.

Driven by an AI boom requiring 16 times more transistors every two years, ASML CEO Christophe Fouquet and industry analyst Dr. Ian Cutress discussed deep tech collaboration, the evolution of Moore’s Law, and Europe's scaling and funding challenges at the Hello Tomorrow conference in Amsterdam.

ASML's Unconventional Origin Story & Ecosystem Strategy

  • Origins as a Spin-off: Spun out of Philips 40 years ago at a time when major semiconductor players like IBM pursued full vertical integration.
  • System Integration Model: Unlike Japanese competitors Nikon and Canon, ASML chose system integration rather than vertical integration, allowing them to partner with the world's best suppliers for every part of the tool.
  • Key Partnerships: Collaborates with Zeiss on optics (a 40-year partnership), VDL, Trumpf (for EUV), and Mistral (for AI).
  • Customer Co-Investment: During the development of EUV when R&D funding was tight, ASML had customers co-invest in the technology to help share the financial burden and accelerate scaling.

Redefining Moore's Law and the AI Infrastructure Boom

  • The Classical vs. AI Definition: While the traditional definition of Moore's Law is the number of transistors per chip doubling every 2 years, AI has put Moore's Law "on steroids."
  • AI Transistor Demand: Advanced AI products require a 16 times increase every 2 years across both logic and memory.
  • Density Drivers: Achieving required density demands scaling complemented by 3D integration (advanced packaging and stacking wafers/dies).
  • Market Visibility: AI now accounts for about half of total semiconductor production. The industry is currently catching up on a significant backlog with a visibility window of 2 to 3 years.

The Hard Reality of Deep Tech Innovation

  • Solving Real Problems: Fouquet emphasized that creativity must serve a concrete purpose—identifying the exact problem to solve and finding customers who deal with that problem daily.
  • The EUV Development Cycle: Theorized in the 1980s, EUV took roughly 20 years to develop, with the first 15 to 18 years consisting largely of a "succession of very painful mistakes" and resilience in solving source power issues.
  • Scaling Over Ideas: Having a great idea is not enough; survival requires operational execution, robust supply chains, and the ability to scale production from one prototype to hundreds of units shipped globally.

AI Infrastructure and the Mistral Partnership

  • Data as the Core Asset: Fouquet stated that the most important part of AI is data, noting that companies must generate unique data to feed powerful customized models rather than relying solely on internet-scale LLMs.
  • Mistral Partnership: ASML partnered with European AI startup Mistral because ASML lacks a DNA in model development despite generating terabytes of data. Mistral is helping build customized models for ASML's products, operations, and R&D.
  • Open Source Alignment: Mistral supports open source because they believe the real value of AI lies in downstream applications and customization.

Europe's Trillion-Dollar Company Challenge

  • European Strengths: Europe maintains strong education systems and well-funded research facilities, consistently producing great ideas and deep tech startups.
  • Scaling Bottlenecks: European startups struggle with access to capital when scaling up (hiring, securing space, purchasing equipment).
  • Regulatory Hurdles: While US and Chinese governments act as enabling bodies with supportive regulations, European governments and the European Commission often create regulatory drag. TL;DR

John Armitage, co-founder of Egerton Capital, outlines his 30-year investment philosophy emphasizing pricing power, rigorous qualitative and numerical modeling, realistic management teams, and downside valuation protection. Hosted by Nicolai Tangen, CEO of Norges Bank Investment Management, the discussion covers stock selection, the risks of AI and over-information, and the realities of running a long/short equity firm.

Defining a Great Company & Investment

  • Moats Versus Management: Moats are critical but insufficient. A company with a moat will fail under poor management (e.g., Boeing under its previous CEO, or Rolls-Royce before its new chief executive).
  • Capital Allocation & Culture: Culture and capital allocation drive long-term value. Berkshire Hathaway transformed from a closed New England textile mill into a powerhouse through capital allocation, while Intel lost its way due to a culture that did not dare to innovate.
  • Filtering New Ideas: Initial idea assessment requires time-value and understandability. Armitage avoids fairly priced businesses to save time and avoids complex industries where management themselves cannot predict outcomes (citing a drug company CFO who treated phase 3 clinical trials like "a series of options").
  • Great Companies vs. Great Investments: Historical greatness does not guarantee future outperformance. Coca-Cola remains a great company with no substitute, but it likely underperformed the market over the trailing 25 years due to a lack of successful new product expansion ("new Coke" failed).

Pricing Power, Margins & Industry Views

  • Definition and Necessity: Pricing power is the ability to raise prices despite competition. It is essential because all companies face cost inflation driven by lower trade barriers and technology-enabled competition. Sustaining pricing power structurally drives margin growth.
  • Cyclicality and Style: The firm invests across cycles without a rigid style definition. Armitage prefers businesses where downside valuation is protected, the market could close without causing worry, and management is realistic rather than overly optimistic or reliant on aggressive accounting.
  • Sectors Avoided: Drug companies are generally avoided. Over a 30-year career, investments have spanned Russian metals, oil and gas, oil services, technology, and retail, but certain industries are avoided today due to high technology-driven competition.
  • Worldview: Macro views need not be overly sophisticated. Armitage views current markets as high, US bond yields and oil prices up, and two wars ongoing, noting that the global economy relies heavily on AI-driven growth and strong US corporate earnings.

Financial Modeling & Analysis

  • The Art of Modeling: Models are for juniors, but fine-art modeling requires focus on key factors. Too much detail leads to "garbage in, garbage out" where minor assumption changes break the model.
  • Private Data and Inference: Many company metrics are private and require detective work.
    • *Airbus (major holding):* Modeled by evaluating units sold times contractually private prices, incremental unit margins, order backlog revenue timing, lumpy R&D costs, and FX.
    • *Reinsurance:* Contracts are private; analysts must evaluate historical reserve development to assess how past losses were estimated.
    • *Nvidia:* Modeled by piecing together bill of materials composition and the impact of memory price inflation on 75% gross margins.
    • *Visa:* A simpler model with clear costs, 67% margins, and less relevant mix effects.
  • Profit & Loss and Balance Sheets: Incremental margins reveal potential outperformance. High incremental margins combined with high starting margins generate major profit beats during sales overshoots. Balance sheet health requires tracking inventory changes, trade terms (payables/receivables), and artificial cash-boosting tactics like factoring receivables.

Evaluating Management & Red Flags

  • Assessing Management: Look for executives who admit mistakes. Michael O'Leary (CEO of Ryanair) is praised for his intense focus on detail, self-awareness, and relentless execution despite treating operations as a series of fixes. In contrast, Pat Gelsinger at Intel was criticized for adding back stock-based compensation to earnings.
  • Red Flags: Consistently missing expectations and unearned optimism. Armitage avoids management teams that present a constantly rosy picture and cannot admit when things go wrong.
  • Case Study (Altis): Selling without margin for error. Altis was a French cable/telecom company utilizing leverage and cost-cutting with flat top-line growth. Armitage sold the position after a slight quarterly miss because a stagnant top-line leaves no room for operational mistakes.
  • Paralysis by Analysis: Information overload increases the risk of over-analyzing. Proliferating global data and analyst commentary risk creating psychological imprinting and decision paralysis.

Valuation & Portfolio Construction

  • Valuation Metrics: Conventional metrics are mandatory; EV-to-EBITDA is dismissed. Armitage relies on P/E ratios, free cash flow multiples, and EV-to-EBIT. He rejects EV-to-EBITDA for capital-intensive or serial acquirers because depreciation and amortization are real costs required to replace capital.
  • Multiples Threshold: Growth-adjusted P/E tolerance. Buying a fast-growing company with double-digit growth at roughly 30 times next year's earnings is considered attractive in the current environment, whereas 35 times earnings (like GE) feels rich.
  • Permanent Capital Rejection: Lockups and permanent capital are potential traps. Armitage rejects permanent capital because it removes the operational tension and discipline required to grapple with proper investment decisions, risking complacency during drawdowns.
  • Portfolio Construction: Concentration carries catastrophic risk. Egerton holds roughly 40 stocks, with top positions sized at 6% to 8%. Armitage rejects extreme portfolio concentration, arguing that while it rewards success, failure leads to disaster. The firm maintains thematic diversification and avoids financial leverage.

AI and Market Efficiency

  • Impact of AI: AI provides instant knowledge access but threatens cognitive ability. AI serves as a tool for knowledge synthesis, but Armitage warns that over-reliance causes mental arithmetic skills to atrophy ("your brain is going to rot").
  • Herd Effects and Alpha: Alpha is harder to capture as markets grow more efficient. AI risks creating a single source of truth and herd behavior, though potential herd effects may create opportunities to trade against the crowd.

Adversarial Code Reviews & Conflict Resolution

  • Catching Downstream Issues:
      • Local code changes often look semantically correct in isolation, but can cause major downstream outages (e.g., a customer serving millions of SMBs where code changes interact directly with databases).
      • Automated just-in-time background workflows continuously calculate software graphs and maps that are too complex for manual human review alone.
  • Coding Agent vs. Review Agent Dynamics:
      • The coding agent and adversarial review agent must first negotiate and agree with each other.
      • Human intervention is triggered only when the agents disagree, or when production incidents occur (which are then codified permanently into the wisdom base to prevent repeating mistakes).

TL;DR

Stack Overflow uses OpenAI's Codex across two distinct R&D tracks: Stack Internal (a constrained enterprise knowledge intelligence layer handling complex authorization and multi-source ingestion) and Stack Overflow for Agents (a net-new, highly autonomous agent-first platform where AI agents consume, validate, and contribute code knowledge linked to human user identities).

Product Portfolio & Codex Implementation

  • Enterprise Product (Stack Internal):
    • Scope: Enterprise-grade knowledge intelligence platform designed for large deployments (supporting 150 to 10,000+ seats, including major banks with 50,000 seats across cloud and on-premise environments).
    • Codex Approach: Prescriptive and guardrail-focused, utilizing existing architectural contracts and service boundaries to operate within safe enterprise containers.
    • Enterprise Complexities Handled: Addressed strict data leakage prevention, authorization models, and variable permissions across diverse raw context sources (Slack, MS Teams, Google Docs, Jira, Confluence, and Notion).
    • API Archetypes: Codex designed the concept of "archetypes" to group common data source patterns (e.g., a "document archetype" covering Google Docs, Notion, and Confluence), reducing what would have been weeks of custom integration logic down to a few days.
    • Engineering Focus: Freed engineers from ingestion plumbing so they could focus on core value delivery—specifically applying Stack Overflow's signature model of trust, verification, and data freshness (e.g., determining whether yesterday's Slack thread from a specific user is more authoritative than an older message).
  • Agent-First Product (Stack Overflow for Agents / SOFA):
    • Scope: A small, experimental, individual-facing platform designed to rethink knowledge consumption and contribution in an agent-first world.
    • Codex Approach: Exploratory and unconstrained ("go rogue"), leveraging Codex to establish new architectural golden paths, decisions, and structural containers.
    • Brand Alignment: Codex suggested maintaining Stack Overflow's brand identity by anchoring each agent's identity to its human creator, inheriting that user's platform reputation.
    • Agentic Capabilities:
      • Active Contribution: Rather than acting solely as "lurkers" consuming data (e.g., via MCP), agents can push production learnings back to the community using "TIL" (Today I Learned) posts and architecture blueprints.
      • Configurable Autonomy: Users can configure agent autonomy levels—ranging from full human approval required before posting to fully autonomous execution on specific topics.
      • Validation Loop: Agents encountering open questions on Stack Overflow can test suggested answers in production, returning to confirm success or provide corrected fixes.

The Right Optimization Metric: Cost Per Task

Right-Sizing Models and Leveraging "Luna Maxing"

  • Defining Success Parameters: Begin by crisply defining the task and the expected business accuracy threshold (e.g., resolving 80% of customer inquiries autonomously).
  • The Pareto Curve Approach: Plot accuracy against cost by testing different models, configurations, and harnesses to identify the optimal threshold balance.
  • Strategic Model Selection:
    • Use smaller, efficient models (like Luna) early in the process for simpler tasks such as text classification or document field extraction.
    • Start with frontier models (like 6 Astra) for high-intelligence planning tasks.
  • Luna Maxing: Luna deployed with high or extra-high reasoning effort frequently outperforms larger previous-generation models and competitors; customers report it successfully handles 80–90% of workflows (such as coding).

Four Non-Model Levers for Cost Reduction

  • Prompt Caching:
    • Reuses the pre-processing of shared input information (such as company policies or support documents) while the model processes new prompt data.
    • Delivers up to 90% cost reduction for cached inputs.

  • Reasoning Effort Adjustments:
